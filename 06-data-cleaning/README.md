# Data Formatting dan Cleansing

## Tujuan
Menguasai teknik pembersihan dan format data agar data siap untuk dianalisis dan tidak bias.

## Materi Yang Dipelajari
- handling missing values
- duplicate data
- type conversion
- standardisasi format tanggal dan teks
- outlier dan validasi data

## Deliverables
- script cleaning data
- dataset bersih yang siap analisis
