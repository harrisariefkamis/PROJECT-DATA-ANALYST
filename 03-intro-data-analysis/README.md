# Intro to Data Analysis

## Tujuan
Memberikan pemahaman dasar tentang analisis data, jenis data, proses analisis, dan peran data dalam pengambilan keputusan bisnis.

## Materi Yang Dipelajari
- definisi dan langkah analisis data
- jenis data dan struktur data
- cara membaca kebutuhan bisnis
- proses dari data ke insight

## Deliverables
- ringkasan analisis bisnis sederhana
- peta proses analisis data
