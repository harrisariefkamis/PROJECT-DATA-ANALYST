# SQL Basic 3: Analyzing Business Data

## Tujuan
Menggunakan SQL untuk menganalisis data bisnis dan menjawab pertanyaan operasional.

## Materi Yang Dipelajari
- analisis penjualan
- segmentasi pelanggan
- performa produk atau channel
- laporan ringkas berdasarkan data transaksi

## Deliverables
- laporan SQL analisis bisnis
- studi kasus satu tabel dan multi tabel
