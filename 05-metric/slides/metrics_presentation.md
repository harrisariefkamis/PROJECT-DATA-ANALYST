# Measure What Matters

A short slide deck on metrics for product & analytics teams.

---

## Key idea
Focus on a small set of actionable metrics (North Star + supporting metrics). Avoid vanity metrics.

---

## Metrics characteristics
- Relevant
- Actionable
- Measurable & reliable
- Understandable
- Sensitive & timely

---

## Frameworks
- North Star Metric
- AARRR (Acquisition, Activation, Retention, Referral, Revenue)
- HEART (Happiness, Engagement, Adoption, Retention, Task success)

---

## Metric Spec (one slide)
Document each metric: name, definition, SQL/formula, time grain, dimensions, owner.

---

## Example SQL
- Retention cohort (day-7)
- DAU
- Conversion rate
(Queries in `/05-metric/sql/`)

---

## Next steps for teams
1. Choose North Star + 3–5 supporting metrics
2. Create metric spec docs in repo
3. Instrument events & validate data quality
4. Build dashboard and alerts
