## Platform belajar dan latihan

### [HackerRank — SQL](https://www.hackerrank.com/domains/sql)

[![HackerRank](HackerRank_Icon-1000px.png)](https://www.hackerrank.com/domains/sql)

HackerRank menyediakan tantangan SQL bertingkat yang dikelompokkan berdasarkan topik dan tingkat kesulitan. Latihannya membantu membangun kebiasaan menulis query untuk mengambil, memfilter, mengelompokkan, dan menggabungkan data.

**Cocok untuk:** latihan terstruktur dan mengukur pemahaman melalui soal. Mulai dari SELECT sederhana, lalu lanjutkan ke agregasi, JOIN, dan subquery.

### [W3Schools — SQL Tutorial](https://www.w3schools.com/sql/)

[![W3Schools](w3schools-logo-icon.png)](https://www.w3schools.com/sql/)

Tutorial interaktif yang menjelaskan konsep dan sintaks SQL dengan contoh yang dapat dicoba. Materinya mencakup SELECT, WHERE, ORDER BY, fungsi agregat, JOIN, serta operasi tabel.

**Cocok untuk:** pemula yang membutuhkan penjelasan singkat dan contoh praktis. Perhatikan bahwa beberapa detail sintaks dapat berbeda antar sistem database; sesuaikan dengan database yang digunakan.

### [LeetCode — SQL 50](https://leetcode.com/studyplan/top-sql-50/)

[![LeetCode](LeetCode_logo_black.png)](https://leetcode.com/studyplan/top-sql-50/)

Kumpulan soal SQL yang berfokus pada pemecahan masalah. Latihan mencakup pengambilan data, JOIN, agregasi, fungsi tanggal, dan topik lain yang sering ditemui dalam soal teknis.

**Cocok untuk:** meningkatkan kemampuan menyusun solusi query secara mandiri dan berlatih untuk wawancara teknis. Periksa ketersediaan soal dan fitur akun di situs LeetCode.

### [SQLBolt](https://sqlbolt.com/)

[![SQLBolt](sqlbolt%20logo.png)](https://sqlbolt.com/)

Pelajaran SQL interaktif berbasis browser dengan penjelasan ringkas dan latihan langsung. Urutannya membantu pemula memahami konsep query secara bertahap.

**Cocok untuk:** memulai dari dasar seperti SELECT, filter, sorting, dan JOIN sambil langsung mencoba query tanpa menyiapkan lingkungan lokal.

### [SQLZoo](https://sqlzoo.net/)

[![SQLZoo](SQLZOO%20icon.png)](https://sqlzoo.net/)

Tutorial dan latihan interaktif SQL dengan materi yang berkembang dari query dasar hingga JOIN, agregasi, dan topik lanjutan. Tersedia latihan yang dapat membantu menguji pemahaman setelah membaca materi.

**Cocok untuk:** latihan bertahap dan memperkuat pemahaman konsep melalui soal. Gunakan dokumentasi database yang dipakai untuk memeriksa perbedaan dialek jika query tidak berjalan sama.

## Urutan belajar yang disarankan

1. Pelajari konsep database, tabel, kolom, dan baris.
2. Kuasai `SELECT`, `FROM`, `WHERE`, `ORDER BY`, dan `LIMIT`.
3. Latih `DISTINCT`, operator logika, dan fungsi agregat dengan `GROUP BY` serta `HAVING`.
4. Pelajari `JOIN` dan pahami relasi antar tabel.
5. Lanjutkan ke subquery, ekspresi `CASE`, dan fungsi window.
6. Kerjakan soal dari beberapa platform dan tulis ulang query dengan pemahaman sendiri.
7. Terapkan SQL untuk menjawab pertanyaan analisis pada dataset nyata.

## Tips latihan

- Baca soal dan pahami bentuk hasil yang diminta sebelum menulis query.
- Pecah pertanyaan kompleks menjadi langkah-langkah kecil.
- Uji query pada kasus batas, misalnya nilai kosong, duplikasi, atau jumlah baris nol.
- Gunakan nama alias yang jelas dan format query agar mudah dibaca.
- Pelajari alasan sebuah query benar, bukan hanya menghafal jawaban.
- Catat perbedaan dialek SQL, khususnya saat berpindah antara PostgreSQL, MySQL, dan SQLite.
