## Tujuan

Memahami proses masuk ke dunia data analysis, menyiapkan mindset belajar, serta mengetahui tahapan yang dibutuhkan untuk membangun fondasi yang kokoh dan karier di bidang data.

## Materi yang Dipelajari

- [ ] Gambaran umum dunia data analyst
- [ ] Target karier dan roadmap belajar
- [ ] Setup lingkungan kerja
- [ ] Manajemen waktu belajar
- [ ] Ekspektasi dan tantangan dalam industri data

## Deliverables

- [ ] Catatan dan notepad personal roadmap belajar
- [ ] Daftar tools yang perlu dipelajari
- [ ] Target belajar mingguan
- [ ] Teori dipahami dulu, baru tes hands-on praktik

---

## Catatan Overview

- **Peran data analyst:** mengubah data mentah menjadi insight yang membantu keputusan bisnis. Pekerjaan harian meliputi query SQL, membersihkan data, membuat dashboard, dan mempresentasikan temuan.
- **Alur belajar:** konsep dan statistik, lalu SQL, lalu Python, lalu visualisasi, lalu portofolio.
- **Ekspektasi realistis:** sebagian besar waktu dipakai untuk membersihkan data. Kemampuan menjelaskan hasil ke non-teknis sama pentingnya dengan kemampuan teknis.
- **Catatan nama:** Google Data Studio sekarang bernama Looker Studio. Gunakan nama baru saat mencari tutorial.

## Daftar Tools

| Kategori | Tools | Keterangan |
|---|---|---|
| Wajib | Excel / Google Sheets | Eksplorasi data cepat |
| Wajib | SQL (PostgreSQL atau MySQL, SQLite untuk latihan) | Inti kemampuan analyst |
| Wajib | Python (Pandas, NumPy, Matplotlib/Seaborn) | Pemrosesan dan analisis data |
| Visualisasi | Looker Studio, Power BI atau Tableau (pilih satu) | Membuat dashboard |
| Lingkungan kerja | Jupyter atau Google Colab, VS Code | Colab tidak butuh instalasi |
| Kolaborasi | Git dan GitHub | Portofolio dan version control |
| Pendukung | Kaggle, Notion atau Obsidian | Dataset latihan dan catatan |

### Checklist setup lingkungan kerja

- [ ] Akun GitHub dan repo portofolio
- [ ] Python dan Jupyter (atau akun Google Colab)
- [ ] VS Code
- [ ] Database lokal (SQLite / PostgreSQL / MySQL)
- [ ] Akun Looker Studio / Power BI / Tableau
- [ ] Akun Kaggle
- [ ] Tempat catatan (Notion / Obsidian / folder `notes/`)
