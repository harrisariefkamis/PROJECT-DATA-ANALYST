# Basic Statistics

## Tujuan
Memahami konsep statistik dasar yang sering digunakan dalam data analysis, terutama untuk menggambarkan dan menganalisis data.

## Materi Yang Dipelajari
- mean, median, mode
- variance dan standard deviation
- distribusi data
- probabilitas dasar
- sampling dan inferensi sederhana

## Deliverables
- notebook statistik dasar
- contoh perhitungan data nyata
