# Project Data Analyst: Visualisasi Data

Proyek ini merupakan bagian dari portofolio Data Analyst yang berfokus pada penyajian hasil analisis melalui visualisasi dan dashboard. Materi dan hasil yang tersedia di folder ini mencakup latihan visualisasi data serta **Campaign Performance Dashboard**, yang merangkum performa kampanye agar metrik dan tren penting lebih mudah dipahami.

## Tujuan

- Mengubah data menjadi grafik dan dashboard yang mudah dibaca.
- Menyajikan metrik performa kampanye untuk membantu mengevaluasi hasil dan membandingkan kinerja.
- Melatih penyusunan laporan visual menggunakan prinsip visualisasi data dan alur kerja yang dapat diterapkan dengan Google Looker Studio.

## Isi folder

- `CAMPAIGN PERFORMANCE DASHBOARD.pdf` — versi PDF dashboard performa kampanye.
- `Campaign Performance Dashboard.jpg` dan `Finpro_Visualization.jpg` — gambar hasil visualisasi proyek.
- `Data_Visualization_page-0001.jpg` dan `Data_Visualization_page-0002.jpg` — materi visualisasi data.
- `latihan_Data_Visualization.pdf` — latihan visualisasi data.

## Alur pengerjaan

1. Siapkan dan pahami data yang akan dianalisis.
2. Tentukan metrik serta pertanyaan bisnis yang ingin dijawab.
3. Pilih visualisasi yang sesuai untuk membandingkan nilai, melihat tren, dan menyampaikan temuan.
4. Susun visualisasi menjadi laporan atau dashboard yang terstruktur dan mudah dipahami.
5. Tinjau kembali hasilnya agar informasi utama tersampaikan dengan jelas.

## Hasil

Dashboard performa kampanye menjadi hasil akhir proyek visualisasi ini. File PDF dan gambar di folder ini dapat digunakan untuk melihat hasil dashboard dan materi pendukung. Proyek ini menunjukkan bagaimana visualisasi membantu mengubah data menjadi ringkasan yang lebih komunikatif untuk mendukung evaluasi kampanye dan pengambilan keputusan.
