# Panduan Kontribusi

Terima kasih telah berkontribusi pada repo `PROJECT-DATA-ANALYST`.

## Pedoman Umum
- Gunakan folder modul sesuai urutan belajar.
- Nama file harus jelas dan konsisten, misalnya:
  - `README.md`
  - `exercise_01.sql`
  - `analysis_notebook.ipynb`
  - `case_study_sales.csv`
- Setiap modul sebaiknya memiliki README yang menjelaskan tujuan, materi, dan deliverables.
- Simpan data contoh di folder `datasets/`.
- Simpan jawaban atau solusi di `solutions/` untuk referensi dan pembelajaran.

## Struktur Folder
```text
module-name/
├── README.md
├── datasets/
├── notebooks/
├── exercises/
├── solutions/
├── slides/
└── notes/
```

## Aturan Commit
- Gunakan commit message yang jelas dan deskriptif.
- Contoh: `Add SQL basic 1 module README`, `Add Python data cleaning exercises`

## Pull Request
- Jelaskan tujuan perubahan pada PR.
- Sertakan ringkasan modul/latihan yang ditambahkan.
- Jika menambah dataset, jelaskan sumber dan lisensi.

## Penamaan Modul
Gunakan format angka + nama modul, misalnya:
- `07-sql-basic-1`
- `12-python-basic-project`
- `15-data-viz-basic`

## Catatan
Jika repo ini dipakai untuk kelas atau bootcamp internal, Anda dapat menyesuaikan struktur ini dengan kebutuhan tim.
